web components library

Lit

A small layer over the browser’s own component standard.

  • Kindweb components library
  • Made byGoogle
  • Since2021 (Lit 2, after LitElement)
  • Written inJavaScript or TypeScript
  • Checked on npm1.0.0 on 2012-07-04, 2.0.0 on 2021-09-21 (the name “lit” was another package before 2021)

At a glance

Pros

Components that work everywhere. Very small library on top of platform features.

Cons

No router, store or full-stack story of its own. Shadow DOM makes global styling and some form handling harder.

What it is

Lit builds components out of the browser’s own Web Components standards: custom elements, shadow DOM and templates. A Lit component is a class registered as an HTML tag, so it works in any page and inside any other framework.

It is the successor to the Polymer project at Google.

How it works

  1. Write a class that extends LitElement
  2. Register it as a custom element
  3. A small library ships
  4. A property change re-evaluates the template and updates only the changed parts

The template is a JavaScript tagged template literal, html`...`. The first render creates the DOM; after that, when a reactive property changes, Lit re-evaluates the template and updates only the parts of the DOM that hold changed values, with no virtual DOM tree.

Because the result is a real custom element, there is no framework boundary to cross: a Lit element can be used from React, Vue, Angular or plain HTML.

Overlaps and differences

Overlaps with

  • Astro: Astro can host Lit components as islands.
  • React: A Lit element can be used inside React.

Differs from

  • React: Lit components are browser elements, React components are not.
  • Svelte: Svelte compiles components away; Lit keeps a small runtime and uses the platform.

What it is good at, and what it costs

Good at

  • Components that work everywhere
  • Very small library on top of platform features
  • Styles are scoped by the browser, with shadow DOM

Costs

  • No router, store or full-stack story of its own
  • Shadow DOM makes global styling and some form handling harder
  • Server rendering is less mature than the meta-frameworks’
