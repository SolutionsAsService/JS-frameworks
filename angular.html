Angular

A complete, opinionated platform: components, router, forms, HTTP and dependency injection.

  • Kindapplication framework
  • Made byGoogle
  • Since2016 (Angular 2; AngularJS, 2010)

At a glance

Pros

Comprehensive framework, built-in TypeScript support, two-way data binding.

Cons

Verbose syntax, steep learning curve, heavy structure.

What it is

Angular is a framework that comes with almost everything an application needs: a component model, a router, form handling, an HTTP client, testing tools and a command-line tool. It is written in TypeScript and requires it.

Angular 2 (2016) was a rewrite of AngularJS, the earlier framework from 2010 which shares its name and is a different thing. Its creators include Miško Hevery, who later made Qwik.

How it works

  1. Write components as TypeScript classes with templates
  2. The Angular compiler turns templates into code ahead of time
  3. A bundle with the runtime ships to the browser
  4. Signals and change detection update the DOM

Components are classes with a decorator that names an HTML template. Services are classes provided through dependency injection: a component asks for what it needs and the framework supplies it.

Angular compiles templates ahead of time. Updating the screen has historically relied on zone.js, which notices asynchronous events and triggers change detection over the component tree. Signals are a newer reactive primitive that tell Angular exactly which bindings changed, and the framework is moving toward updates driven by signals instead of zones.

Overlaps and differences

Overlaps with

  • Vue: HTML templates with directives for conditions and loops.
  • Qwik: Created by the same person (Miško Hevery), with the opposite answer on how much work to do at start-up.

Differs from

  • React: React is one library of UI parts; Angular is a platform that decides the router, forms and HTTP client for you.
  • Svelte: Svelte ships little runtime; Angular ships a framework.

What it is good at, and what it costs

Good at

  • Everything is included and designed to fit together
  • Strong conventions help large teams keep code alike
  • Typed from templates to services

Costs

  • The most concepts to learn first: modules or standalone components, injection, decorators, RxJS
  • Starts larger than the small libraries, because the platform comes with it (see the measured figure)
  • Opinionated: leaving its conventions is harder than in a library
