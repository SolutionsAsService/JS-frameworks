Vue meta-framework

Nuxt

Vue with routing, server rendering and a server built in.

  • KindVue meta-framework
  • Made bySébastien and Alexandre Chopin
  • Since2016
  • Written inJavaScript or TypeScript, with Vue
  • Checked on npmfirst version 2016-10-26, 1.0.0 on 2018-01-08

At a glance

Pros

A full-stack Vue app with little configuration. Rendering mode chosen per route.

Cons

Convention and auto-imports hide code paths that a plain Vue app shows. Adds a server runtime and build step to Vue’s own.

What it is

Nuxt is the framework for building complete applications with Vue. It gives file-based routing, layouts, data-fetching helpers, automatic imports of components and composables, and a server layer.

Its server engine is Nitro, which can output a Node server, static files or functions for many hosting platforms from the same code.

How it works

  1. Files under pages/ become routes
  2. The Nitro server renders HTML for each route
  3. HTML and the Vue client code reach the browser
  4. Vue hydrates and takes over

Each route can be rendered on the server per request, at build time, or on the client only, set per route with route rules. The server sends HTML, and Vue then hydrates it in the browser.

Because routes and components are found by convention, most of the wiring a Vue app would need (router setup, imports) is generated for you.

Overlaps and differences

Overlaps with

  • Next.js: The same job for a different view library: routing, rendering modes, server code.
  • Vue: Components are ordinary Vue components.

Differs from

  • Next.js: Nuxt’s Vue reactivity rarely needs hand-written memoization, and its auto-imports remove import lines that Next.js code spells out.
  • Astro: Astro sends no framework runtime unless a page asks for an island.

What it is good at, and what it costs

Good at

  • A full-stack Vue app with little configuration
  • Rendering mode chosen per route
  • Deploys to many hosts from one code base

Costs

  • Convention and auto-imports hide code paths that a plain Vue app shows
  • Adds a server runtime and build step to Vue’s own
  • Smaller than Next.js in community and hosting integrations
