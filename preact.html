UI library

Preact

React’s API in a small package.

  • KindUI library
  • Made byJason Miller
  • Since2015
  • Written inJavaScript or TypeScript, with JSX
  • Checked on npmfirst version 2015-09-11

At a glance

Pros

React’s model at a fraction of the download (see the measured figure). Most React libraries work through the compatibility layer.

Cons

Not every React feature or library behaves identically. Smaller team and ecosystem than React.

What it is

Preact is a lightweight alternative to React that keeps the same component and hooks API. It is made to be small, and its compatibility layer, preact/compat, lets many React libraries run on it.

It also offers signals in a separate package, which are reactive values that update the parts of the UI that read them without re-running whole components.

How it works

  1. Write components in JSX
  2. A build step turns JSX into function calls
  3. preact ships to the browser
  4. State changes re-run components; Preact diffs and patches the DOM

Preact’s diffing works on the same idea as React’s virtual DOM. It leaves out features such as React’s concurrent scheduling and synthetic event system, which is where the saving in size comes from.

Many tools, Astro among them, accept Preact as a drop-in for React in places where the bundle size matters.

Overlaps and differences

Overlaps with

  • React: Same API, same JSX, same hooks.
  • Astro: A common choice for Astro islands.

Differs from

  • Solid: Preact still re-runs components and diffs; Solid does not.
  • React: Smaller, with fewer built-in features.

What it is good at, and what it costs

Good at

  • React’s model at a fraction of the download (see the measured figure)
  • Most React libraries work through the compatibility layer
  • Fast to start

Costs

  • Not every React feature or library behaves identically
  • Smaller team and ecosystem than React
  • Newest React features reach it later, or not at all
