UI library

Solid

React’s look with no re-rendering: signals update only what read them.

  • KindUI library
  • Made byRyan Carniato
  • Since2021 (1.0)
  • Written inJavaScript or TypeScript, with JSX
  • Checked on npm1.0.0 on 2021-06-28

At a glance

Pros

Updates are targeted by construction. React-like syntax eases the move for React developers.

Cons

A far smaller ecosystem than React’s. Habits from React (destructuring props, conditionals in JSX) can silently break reactivity.

What it is

Solid looks like React: components are functions and the markup is JSX. The difference is that a component function runs once. The state it creates, with createSignal, is a reactive value, and the places in the JSX that read it become subscriptions.

SolidStart is the application framework for routing and server rendering.

How it works

  1. Write components in JSX
  2. The compiler turns JSX into direct DOM creation and signal subscriptions
  3. A small reactive runtime ships
  4. A signal change updates the exact DOM node that read it

The JSX compiler turns each expression in the markup into an effect that reads signals. When a signal changes, only those effects run and the matching DOM nodes are updated; no component function is called again and no tree is compared.

This is why reading a signal in Solid means calling it, count(), and why destructuring props can lose reactivity.

Overlaps and differences

Overlaps with

  • React: The same JSX authoring.
  • Svelte: Both update the DOM without a virtual DOM.

Differs from

  • React: In React the component function re-runs on change; in Solid it runs once.
  • Vue: Vue tracks reads per component render; Solid tracks per expression.

What it is good at, and what it costs

Good at

  • Updates are targeted by construction
  • React-like syntax eases the move for React developers
  • Small runtime

Costs

  • A far smaller ecosystem than React’s
  • Habits from React (destructuring props, conditionals in JSX) can silently break reactivity
  • A younger framework ecosystem and tooling
