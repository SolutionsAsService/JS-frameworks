Vue

Templates and reactive state that you can adopt a piece at a time.

What it is

Vue is a framework for building interfaces from components. Each component is usually one .vue file with a <template> written in HTML-like syntax, a <script> and optionally a <style>. It is described as progressive: it can be added to one page with a script tag, or used as a full build-tooled app.

The official router (Vue Router) and state store (Pinia) are separate packages that the project maintains alongside the core.

How it works

  1. Write a .vue file: template, script and style together
  2. The compiler turns the template into optimised render functions
  3. vue ships to the browser
  4. A change to reactive state re-renders only the components that read it

Vue 3 wraps state in reactive proxies. While a component renders, Vue records which reactive values it reads; when one of those changes, only the components that read it are scheduled to render again. The developer rarely writes memoization.

Templates are compiled ahead of time. The compiler marks which parts of a template are static and which can change, so the update step skips the static parts. Under the hood there is still a virtual DOM; Vapor Mode is an in-development compile mode that drops it.

Overlaps and differences

Overlaps with

  • Svelte: Both use single-file components with an HTML-like template, compiled ahead of time.
  • Nuxt: Nuxt is the full-stack framework on top of Vue.
  • Angular: Both use HTML templates with directives for loops and conditions.

Differs from

  • React: React’s model is re-run the function and diff; Vue’s is track what was read and update just that.
  • Solid: Solid tracks reads too, but at the level of single expressions, with no component re-render and no virtual DOM.

What it is good at, and what it costs

Good at

  • Gentle to adopt: HTML-like templates, one file per component
  • Fine-grained updates without hand-written optimisation
  • Official router, store and build tool (Vite, also made by Evan You) that fit together

Costs

  • Two ways to write components (Options API and Composition API) coexist
  • A smaller job market and library catalogue than React
  • Templates are a separate language from JavaScript, which is a gain for some teams and a loss for others
