Svelte

A compiler that turns components into direct DOM updates.

  • Kindcompiler and UI framework
  • Made byRich Harris
  • Since2016
  • Written inJavaScript or TypeScript, in .svelte files
  • Checked on npmfirst version 2016-11-17, 1.0.0 on 2016-11-29

At a glance

Pros

Compiles to efficient vanilla JavaScript, minimal runtime overhead, simple syntax.

From the first version of this site.

Cons

Smaller community, less mature tooling and ecosystem.

From the first version of this site.

What it is

Svelte is a compiler. A .svelte file holds markup, script and style, and the build turns it into plain JavaScript that creates and updates the DOM, so less of a framework has to be sent to the browser.

SvelteKit is the application framework around it: file-based routes, server rendering, form handling and adapters for deploying to different hosts.

How it works

  1. Write a .svelte file
  2. The compiler turns it into JavaScript that updates the DOM directly
  3. Only that output and a small runtime ship
  4. A change runs just the code for what depended on it

Svelte 5 introduced runes, such as $state and $derived, to mark reactive values. The compiler sees where each is used and writes code that updates only those places when they change; there is no virtual DOM to diff.

Because the work is decided at build time, a small component can compile to very little code. The cost is that the compiler is part of the toolchain, and a component’s reactivity is understood by reading the compiler’s rules.

Overlaps and differences

Overlaps with

  • Vue: Single-file components with HTML-like templates.
  • Solid: Both do fine-grained updates with no virtual DOM, Solid at run time through signals and Svelte mostly at compile time.

Differs from

  • React: React sends a runtime that diffs; Svelte sends compiled updates.
  • Angular: Angular ships the platform; Svelte ships the component.

What it is good at, and what it costs

Good at

  • Small output for small apps (see the measured figure)
  • Little boilerplate: state is a variable
  • SvelteKit supplies routing and rendering modes

Costs

  • A smaller ecosystem and fewer jobs than React or Angular
  • A compiler step and its own syntax, which tools must support
  • The runes model replaced the earlier reactive syntax, so older tutorials differ
